# coachmark-onboarding

A robust, portal-based coachmark (onboarding/walkthrough) library for React Native and Expo.

## Vision
To provide a seamless, highly customizable, and performant onboarding experience for React Native applications. By leveraging portal-based rendering, we ensure coachmarks appear above all other UI elements, providing a consistent look and feel across different screens and navigation structures.

## Features (Planned)
- Expo & React Native Compatible: Built with Expo Modules API.
- Portal-Based Rendering: Guarantees coachmarks stay on top.
- Fully Customizable: Style the tooltips, backdrops, and highlights.
- Responsive: Works across various screen sizes and orientations.
- Easy Integration: Simple API to get you started in minutes.

## Installation
```bash
npx expo install coachmark-onboarding
# or
npm install coachmark-onboarding
```
